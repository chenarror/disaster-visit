# 112年度 臺南市永康區永康國民小學 校園災害防救計畫

本專案將《永康國小112年校園災害防救計畫書.pdf》（共 66 頁）完整轉換為互動式防災校園資訊網站與 3D 疏散模擬地圖。

## 網站內容架構
- [`index.html`](./index.html)：主頁面
  - **壹、學校基本資料與潛在災害評估**：基本資料、計畫修訂歷程時間軸、周邊道路圖（圖2.1）、校園平面配置圖（圖2.2）、地震與淹水災害潛勢圖（圖2.4.1、2.4.2）及歷年災害事件紀錄表（表2.5）。
  - **貳、人員結構與校園災害防救組織**：教職員工（179人+志工60人）與學生結構（2,505人/94+3班）視覺化長條圖、防災組織架構圖（圖2.5）、平時減災分工表（表2.6）與緊急應變小組六組完整成員名冊互動篩選器（表2.7.1）。
  - **參、防災地圖、逃生路線與應變流程**：各類災害避難原則、應變核心步驟、互動式各階段應變行動腳本時間軸、內嵌互動式 3D 防災地圖、高清校園防災地圖（圖3.3）與 **全校 7 棟校舍＋獨立午餐廚房互動檢視器**（含結構安全資料、避難設備與全部樓層平面圖）。
  - **肆、減災整備、應變器材檢核與復原措施**：減災與自主調查流程圖（圖3.1、3.2）、112年度應變器材盤點與待補強項目（夜間警示燈）、31 項應變器材互動檢核表（表3.1）、外部支援單位聯絡清冊（表3.2）與災後心理輔導資源（表5.1）。
  - **伍、原始文件與防災資訊網**：原始 PDF 計畫書、3D 地圖、高解析圖檔與政府防災公開資訊網連結（表2.4）。
- [`evacuation-3d-view.html`](./evacuation-3d-view.html)：互動式 3D 防災地圖（含校園 3D 量體、200 人疏散人流模擬、行政大樓 1F–4F 立體樓層與動線、設施定位、平面配置圖縮放檢視及圖檔打包下載）。
- [`documents/disaster-plan.pdf`](./documents/disaster-plan.pdf)：永康國小 112 年校園災害防救計畫書原始 PDF。
- [`assets/`](./assets/)：自 PDF 擷取之 56 張高解析度校園地圖、各棟建築外觀與各樓層平面圖、潛勢圖及流程圖。
